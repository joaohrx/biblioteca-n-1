# Biblioteca n+1
Componentes:
- Edson Félix dos Santos
- João Pedro de Oliveira Silva
- João Victor Rocha dos Santos

Dividimos nossas responsabilidades de acordo com o modelo MVC. Edson será responsável pela seção de Controller, João Pedro pelo Model e João Victor pelo View.

A Biblioteca n+1 é um website com um sistema moderno de gerenciamento de livros, permitindo que usuários cadastrados realizem empréstimos e devoluções de livros. Além disso, é possível cadastrar, editar e excluir novos livros, bem como realizar filtragem por autor ou por título.
